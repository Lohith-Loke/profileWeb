You are given an `m x n` integer array `grid`. There is a robot initially located at the top-left corner (i.e., `grid[0][0]`). The robot tries to move to the bottom-right corner (i.e., `grid[m - 1][n - 1]`). The robot can only move either **down** or **right** at any point in time.

An obstacle and a free space are marked as `1` and `0` respectively in `grid`. A path that the robot takes cannot include any square that is an obstacle.

Return the number of possible unique paths that the robot can take to reach the bottom-right corner.

The testcases are generated so that the answer will be less than or equal to `2 * 10⁹`.

## Example 1

Input: obstacleGrid = [[0,0,0],[0,1,0],[0,0,0]]

Explanation: There is one obstacle in the middle of the 3x3 grid above.
There are two ways to reach the bottom-right corner:

1. Right -> Right -> Down -> Down
2. Down -> Down -> Right -> Right


## Solution

**Idea:** to reach any cell, the robot can only have arrived from the cell above it or the cell to its left. So the number of ways to reach `(i, j)` is just the sum of the ways to reach those two neighbors:

If `grid[i][j]` is not an obstacle:

```
dp[i][j] = dp[i-1][j] + dp[i][j-1]
```

If `grid[i][j]` **is** an obstacle, no path can pass through it:

```
dp[i][j] = 0
```

`dp[i][j]` represents the number of distinct ways to reach cell `(i, j)`. The starting cell `dp[0][0]` is `1` (there's exactly one way to be at the start: don't move), unless it's itself an obstacle, in which case the whole grid is unreachable and the answer is `0`. Cells along the first row and first column only have one possible neighbor to come from (left or above respectively), so they simply inherit that neighbor's value — which becomes `0` the moment an obstacle blocks the row or column. The final answer ends up sitting in `dp[m-1][n-1]`.

```python
class Solution:
    def uniquePathsWithObstacles(self, obstacleGrid: List[List[int]]) -> int:
        if obstacleGrid[0][0] == 1:
            return 0

        m, n = len(obstacleGrid), len(obstacleGrid[0])
        dp = [[0] * n for _ in range(m)]
        dp[0][0] = 1

        for i in range(m):
            for j in range(n):
                if obstacleGrid[i][j] == 1:
                    dp[i][j] = 0
                elif i == 0 and j == 0:
                    continue
                else:
                    top = dp[i - 1][j] if i > 0 else 0
                    left = dp[i][j - 1] if j > 0 else 0
                    dp[i][j] = top + left

        return dp[-1][-1]
```

> **Space optimization:** since each row of `dp` only ever depends on the row directly above it, you can collapse the 2D table down to a single 1D array of size `n` and update it in place, bringing space down to `O(n)`. It's a nice follow-up once the 2D version above makes sense.

### Complexity

- **Time:** `O(m · n)` — every cell is visited exactly once.
- **Space:** `O(m · n)` for the `dp` table (or `O(n)` with the 1D optimization above).
